# Security Policy

## Supported versions

This project is in early development. Security fixes are applied to the default development branch; no formal long-term support versions are currently offered.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed security vulnerability. Contact the repository maintainer privately through the security reporting option on GitHub:

https://github.com/viomborsadiya/Annotation/security/advisories/new

Include the affected version or commit, impact, reproduction steps, and any suggested mitigation. Please allow reasonable time for investigation and a fix before public disclosure.

## Data handling

The current application processes selected image files in the browser and has no application backend. This is not a security guarantee for the browser, operating system, or device on which it runs. Avoid loading untrusted files on devices where you do not have permission to do so.
